========================================
🔐 VALORES PARA COPIAR E COLAR NOS SECRETS DO GITHUB
========================================

⚠️  IMPORTANTE: Substitua "SEU_IP_DA_VPS" pelo IP real do seu servidor!

========================================
SECRETS PARA DEVELOPMENT (develop):
========================================

Nome: DEV_SSH_HOST
Valor: SEU_IP_DA_VPS
(ex: 72.61.134.237)

Nome: DEV_SSH_USERNAME
Valor: root

Nome: DEV_SSH_PORT
Valor: 22

Nome: DEV_PROJECT_PATH
Valor: /var/www/conectades-dev

Nome: DEV_SSH_PRIVATE_KEY
Valor: Execute no terminal e copie TODO o output:
  cat ~/.ssh/id_rsa_conectades

========================================
SECRETS PARA PRODUCTION (main):
========================================

Nome: PROD_SSH_HOST
Valor: SEU_IP_DA_VPS
(mesmo IP ou diferente se tiver outro servidor)

Nome: PROD_SSH_USERNAME
Valor: root

Nome: PROD_SSH_PORT
Valor: 22

Nome: PROD_PROJECT_PATH
Valor: /var/www/conectades-prod

Nome: PROD_SSH_PRIVATE_KEY
Valor: Execute no terminal e copie TODO o output:
  cat ~/.ssh/id_rsa_conectades

========================================
COMO ADICIONAR NO GITHUB:
========================================

1. Acesse: https://github.com/Bigu-Comunicativismo/conectades-back/settings/secrets/actions

2. Clique em "New repository secret"

3. Cole o Nome e o Valor correspondente

4. Clique em "Add secret"

5. Repita para todos os secrets acima

========================================
CHAVE PÚBLICA PARA COPIAR NO SERVIDOR:
========================================

Execute no terminal:
  cat ~/.ssh/id_rsa_conectades.pub

Copie o output e adicione no servidor em:
  ~/.ssh/authorized_keys

OU use o script automático:
  ./copiar-chave-para-vps.sh
